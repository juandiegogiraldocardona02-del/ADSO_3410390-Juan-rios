El DOM (Document Object Model): Es la representación en memoria que hace el navegador del documento HTML como un árbol de objetos, permitiendo que JavaScript modifique elementos, atributos y estilos en tiempo real.

Cuando múltiples reglas CSS compiten por estilizar el mismo elemento, el navegador calcula la **especificidad** asignando un puntaje jerárquico:

  • Estilos Inline: 1000 puntos
  • Selectores por ID (#id): 100 puntos
  • Selectores por Clase, Atributo o Pseudo-clase (.class): 10 puntos
  • Selectores por Etiqueta o Pseudo-elemento (p, div): 1 punto
Reset vs Normalize: Un Reset elimina por completo los márgenes y paddings por defecto de los navegadores para partir desde cero. Normalize.css estandariza los estilos manteniendo comportamientos útiles predeterminados.

Todo elemento en HTML se interpreta como una caja rectangular compuesta por capas concéntricas:

  1. Content: El texto o imagen interior.
  2. Padding: Espacio de relleno interno entre el contenido y el borde.
  3. Border: La línea que envuelve el padding y el contenido.
  4. Margin: Espacio externo que separa la caja de otros elementos vecinos.
Usa siempre box-sizing: border-box; en tus selectores universales para evitar que el padding y los bordes sumen ancho extra al tamaño de tus cajas.

La propiedad display define cómo se comporta un elemento dentro del flujo de la página:

  • block: Ocupa todo el ancho disponible y fuerza un salto de línea (ej. <div>, <p>).
  • inline: Ocupa solo el ancho de su contenido y no permite modificar ancho ni alto (ej. <span>, <a>).
  • inline-block: Se alinea en línea como un texto pero respeta propiedades de ancho, alto y márgenes.
