Punto 1: Etiquetas Semánticas vs No Semánticas

Diferencia principal: Las etiquetas semánticas comunican la estructura y significado del contenido a los navegadores, buscadores y lectores de pantalla. Las no semánticas actúan solo como contenedores visuales sin peso sintáctico.

Etiquetas Semánticas (5 Ejemplos) Etiquetas No Semánticas (5 Ejemplos)
<header>, <nav>, <main>, <article>, <footer> <div>, <span>, <b>, <i>, <font>

Accesibilidad Web: Facilitan la lectura para personas con discapacidad visual que usan lectores de pantalla mediante la navegación por referencias clave (landmarks).

Punto 2: El DOM (Document Object Model)

El DOM es una interfaz de programación que representa la estructura HTML en un árbol de objetos dentro de la memoria del navegador. Es fundamental para manipular dinámicamente el contenido, estilos y atributos con JavaScript.

Punto 3: Especificidad en CSS

El navegador resuelve conflictos de estilos evaluando esta jerarquía de puntos:

  • Estilo Inline (en etiqueta HTML): 1000 pts
  • Selector por ID (#mi-id): 100 pts
  • Selector por Clase (.mi-clase): 10 pts
  • Selector por Etiqueta (p, div): 1 pt

Punto 4: Reset CSS vs Normalize.css

Un Reset CSS elimina todos los valores predeterminados de márgenes, paddings y bordes asignados por diferentes navegadores para construir el diseño desde cero de forma consistente.

Punto 5: Mobile First vs Responsive Web Design

Responsive Web Design: Estrategia global para adaptar un sitio web a pantallas de cualquier resolución.

Mobile First: Metodología de desarrollo donde se maqueta primero la experiencia para dispositivos móviles y se adapta a pantallas grandes a través de @media queries.

Punto 6: Pseudo-clases y Pseudo-elementos

Pseudo-clases (:): Aplican estilos basándose en estados del elemento (ej: :hover, :focus, :nth-child()).

Pseudo-elementos (::): Estilan una parte concreta de un elemento o generan contenido (ej: ::before, ::after, ::first-letter).

Puntos 11 y 12: Unidades de Medida y Sistemas de Color

Unidades: Absolutas (px), Relativas a la Fuente (rem, em), Relativas al Viewport (vw, vh) y Porcentajes (%).

Sistemas de Color: Keywords (red), HEX (#3498db), RGB/RGBA (rgb(52,152,219)), HSL/HSLA (hsl(204,70%,53%)).
